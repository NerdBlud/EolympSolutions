# Eolymp solutions by NerdBlud

This repository contains C++ and Python solutions for [Eolymp](https://www.e-olymp.com/) programming problems. Use them to review approaches to algorithms, data structures, and competitive programming problems.

## Find a solution

Look for the problem ID in the folder for its numeric range. For example, problem 2 is [Digits](1-1000/2%20-%20Digits.cpp) in the [1–1000 folder](1-1000/).

## Run a solution

Run each solution individually and supply the problem's sample input on standard input.

For C++, compile the file with GCC's C++ compiler, then run the executable.

```powershell
g++ -std=c++17 "1-1000/2 - Digits.cpp" -o digits.exe
"42" | .\digits.exe
```

The program prints `2`. For Python solutions, run the file with Python 3.

```powershell
"X+V" | python "1-1000/7 - Roman numerals.py"
```

The program prints `XV`. For practice, try solving the problem before reading the solution.

## Решения задач Eolymp

В репозитории собраны решения задач [Eolymp](https://www.e-olymp.com/) на C++ и Python. Папки сгруппированы по диапазонам номеров задач. Например, решение задачи 2 находится в папке [1–1000](1-1000/).

Запускайте каждое решение отдельно и передавайте входные данные через стандартный ввод. Для тренировки сначала попробуйте решить задачу самостоятельно.
